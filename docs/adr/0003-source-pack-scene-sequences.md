# Model the First Scene Sequence as a Source Pack

One Source Pack holds a `sequence.yaml` for shared geography and three named Scenes: rainfall overload, river back-pressure, and tide-blocked outflow. `render-sequence` validates all source, license, retrieval, geometry, and CRS data before rendering numbered 4K, 30 fps PNG frames plus a manifest; the Attribution Card states that the geography is source-backed and timing illustrative.
